# Modelos de peça

Esta pasta recebe os modelos do escritório (.docx), montados sobre o papel timbrado oficial (modelo A), com os campos entre colchetes, por exemplo `[CLIENTE]`, `[PROCESSO]`.

A advogada não tem modelos próprios (questão 18) e aceitou que sejam criados modelos gerais por área. Nenhum modelo pode conter dados de clientes reais. Use modelos em branco.

Primeiros modelos a criar, pela ordem de uso:

1. `procuracao.docx`, `contrato-honorarios.docx`, `declaracao-hipossuficiencia.docx` (documentos de praxe de todo caso novo).
2. `requerimento-administrativo-inss.docx` e `requerimento-administrativo-rpps.docx`.
3. `peticao-inicial.docx`, com variações por área quando necessário.
4. `contrarrazoes.docx`.
