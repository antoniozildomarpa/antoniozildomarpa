# Modelos de peça

Esta pasta recebe os modelos do próprio escritório (.docx ou .md), com os campos entre colchetes, por exemplo `[CLIENTE]`, `[PROCESSO]`, `[OAB]`.

Nenhum modelo de peça real deve ser colocado neste pacote se contiver dados de clientes. Use modelos em branco.

Nomes sugeridos: `peticao-inicial-civel.docx`, `contestacao.docx`, `recurso-apelacao.docx`, `notificacao-extrajudicial.docx`.
