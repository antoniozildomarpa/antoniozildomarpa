# Ferramentas avaliadas

Índice das ferramentas consideradas para o escritório, com a ordem de avaliação e o status de cada uma.

Ordem: primeiro as ferramentas nativas do Claude, depois as de terceiros. Só se passa adiante quando a anterior estiver aprovada ou descartada.

## Arquivos

- [`01-claude-nativo.md`](01-claude-nativo.md): skills de Word, PDF e planilha, Claude Docs, visualização, Claude Code, rotinas, Claude in Chrome e app desktop.
- [`02-terceiros.md`](02-terceiros.md): pesquisa jurisprudencial, plugins do catálogo e ferramentas descartadas.

## Critérios gerais

1. **Dados de clientes** só entram em ferramenta que ela tenha avaliado, com tratamento de dados adequado.
2. **Teste antes de usar**: todo item passa primeiro por dados fictícios (`[~]`).
3. **Aprovação explícita** antes de `[x]`, feita por ela.
4. **Conferência de fontes** continua valendo, qualquer que seja a ferramenta.

## Ordem sugerida de teste

1. Skills de Word, PDF e planilha (sem instalação extra).
2. Claude Code, com as skills do pacote.
3. Claude in Chrome, para consulta de portais.
4. Claude Docs, para revisão de minutas.
5. Skill de visualização, para o painel financeiro.
6. Rotinas agendadas, depois que os itens anteriores estiverem aprovados.
7. App desktop, para programas locais.
8. Ferramentas de terceiros, uma de cada vez: primeiro o conector de pesquisa, depois os plugins.
